Integration test output review

The images the live generation tests saved, next to what each one should show and how its test went. No test checks that an image matches its prompt: that part is yours.

How to review

  • Run pytest tests/ --run-generation with a backend up, then reload this page.
  • Each test overwrites only its own files, and its result here. An image marked as older than its test's run was left by an earlier run, because the latest run skipped or failed before saving it.
  • Generated images are small and use few steps, so soft, low-detail output is expected. Judge whether each image follows its prompt and inputs, not its quality.
  • Inputs (*_source, *_mask, *_input) are drawn by tests/helpers.py and are the same on every run. A change in one points to the test helpers, not the backend.
  • Click any image to zoom. In the overlay, click to zoom in at a point, use the arrow keys to step through images and Esc to close.
